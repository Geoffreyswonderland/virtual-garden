# 歸園田居：虛擬園藝活動雛形

中興大學園藝學系造園組專題討論的展示雛形。以陶淵明〈歸園田居〉為故事線，使用者以第一人稱在一座田園裡**自由走動**，過完一天：

| 段落 | 時辰 | 做什麼 | 出現的詩句 |
| --- | --- | --- | --- |
| 返自然 | 清晨 | 在柴門外聽著車馬聲，推開柴門 | 久在樊籠裡，復得返自然（其一） |
| 理荒穢 | 早晨→正午 | 拿起靠在家門邊的鋤頭，從屋後小門出去，沿小路走到南山腳下的豆田；在稀疏的豆苗之間按住拔草，丟進田邊竹簍（別拔到豆苗）。天色隨除草進度推進 | 種豆南山下，草盛豆苗稀；晨興理荒穢 |
| 補苗 | 正午→黃昏 | 草除掉後看見豆苗的空缺：用鋤頭挖洞、放三顆豆子、蓋土。天色隨工作推進 | （回應「豆苗稀」） |
| 荷鋤歸 | 黃昏→夜 | 扛著鋤頭沿原路回家：小路很窄、兩旁草比人高，衣襬在路上被夜露沾濕；月亮從家的方向升起，畫面邊緣的箭頭指出月亮，抬頭看它一會兒 | 帶月荷鋤歸，道狹草木長；夕露沾我衣，衣沾不足惜 |
| 歸 | 夜深 | 推門進屋（屋裡有木榻、灶、水缸、茶具、無弦琴與酒罈），把鋤頭掛到進門左手邊牆上的木釘，坐到窗邊；自己決定何時結束 | 但使願無違 |

### 與原詩的對應

依據的解說：「中國古詩文精讀」〈歸園田居（其三）〉（註釋引香港商務印書館《中國文學古典精華》、導賞引林梅英《古詩選讀》）、肖鷹〈陶淵明《歸園田居》與中國鄉村美學〉（清華大學，原刊《光明日報》）；延伸閱讀：楊玉成〈田園組曲：論陶淵明《歸園田居》五首〉，《國文學誌》4（2001）。

- **南山**：廬山。豆田在山腳下，離住處有一段路，所以豆田放在屋後柴門外，而不在院子裡。
- **草盛豆苗稀**：豆子已經出苗，只是雜草比苗多；所以詩裡沒有「播種」，遊戲改成在豆苗間除草，下午在缺苗處補種。
- **晨興理荒穢，帶月荷鋤歸**：同一天從清晨除草到月出才回家；天色隨使用者做事的進度推進。
- **道狹草木長，夕露沾我衣**：都是從田地回家路上的經驗：田間小路窄、草木高，衣裳在路上被露水打濕。
- **但使願無違**：願指歸隱躬耕、不違本性的心願。

〈歸園田居〉其三的每一句，都在對應的動作或地點出現（有保底，不會漏掉）；另有 5 張「詩箋」（其一的景物詩句與〈飲酒〉其五）散落在園子裡，找不找得到都沒關係。找到的詩句收在選單的「詩卷」裡。

每一段結束時，只問一題「此刻有多放鬆」（同一張卡片上會列出這段遇到的詩句）；最後的幾題在故事結束後，集中在同一頁作答。結果頁顯示放鬆程度的時間軸與走動軌跡俯視圖，並可下載完整的事件紀錄。

本雛形用來展示**過程測量**的可能性：傳統研究只在活動前後各測一次，這裡記錄的是活動進行中的變化，以及走動軌跡、停留時間、看月亮、走進草地這類行為資料。

> 這是展示與可行性測試用的雛形，不收集受試者資料。紀錄只存在使用者自己的裝置上，除非他按下「下載紀錄」。

## 操作

- **點地面**：點一下地面就會走過去（最直覺，平板和電腦都適用）。
- **搖桿**：往上推前進、往下退後、往左右推是轉身（不是側移）。平板上，左手拇指放在畫面左下任何地方，搖桿就會出現在那裡。
- **鍵盤**：W／S 或 ↑／↓ 前進後退，A／D 或 ←／→ 轉向，Q／E 側移，R／F（或 PageUp／PageDown）抬頭、低頭，按住 Shift 走快一點。
- **環顧**：在畫面上拖曳，景物會跟著手移動（滑鼠和觸控都一樣，和街景地圖相同）。
- **互動**：點東西本身（太遠會自動走到旁邊），或走近後點右下角的圓形按鈕。
- **拔草**：在豆田裡，草和豆苗長在一起（豆苗矮、葉子圓）。按住草本身、右下角按鈕或空白鍵，草會抖動、慢慢鬆動，按夠久才連根帶土拔起；太早放手會縮回去；點到豆苗它只會晃一下，並記錄下來。拔起的草只能放進田邊的竹簍（上方有「竹簍」標示）。按住草本身拔的，可以手指不放、直接拖到竹簍上放開；用按鈕或空白鍵拔的，草會拿在手上跟著你轉身，轉向竹簍後點竹簍、按「丟進竹簍」或空白鍵就丟進去（4.5 公尺內都可以）。
- **補苗**：拿起插在田邊的鋤頭 → 在插著小枝的空缺處按住挖洞（鋤頭會一下一下挖下去）→ 拿田邊木樁上的種子袋，走到每個洞旁邊放進三顆豆子 → 按住用鋤頭把土蓋回去。豆子不會當場發芽。
- **帶我過去**：右上角任務框裡的連結，會沿著小路自動走到目標（紀錄裡會記下使用次數）。

為了降低頭暈，沒有走路晃動，起步和停下都有緩衝。

每一段有多個步驟時，任務框下方會列出步驟，目前這一步會亮起；第一次遇到新動作（拔草、挖洞、放豆、蓋土、澆水）時，畫面下方會出現一張簡短的教學卡。可以互動的地方地上會有發亮的圈圈，走到夠近時圈圈變綠，上方會出現動作名稱。

## 用 Excel 修改內容

旁白、任務文字、詩句和題目都放在 `data/` 的兩個 CSV 檔裡，改內容不需要動程式。

1. 用 Excel 打開 CSV，修改文字。
2. 另存新檔時選 **「CSV UTF-8（逗號分隔）」**，否則中文會變成亂碼。
3. 把檔案上傳回 GitHub 的 `data/` 資料夾，覆蓋原檔。也可以直接在 GitHub 網頁上點檔案、按鉛筆圖示編輯。

### 問卷的學理依據

測量分三層，各對應一組題目：

1. **恢復結果**（使用者有沒有恢復）：恢復結果量表 Restoration Outcome Scale（ROS；Korpela, Ylén, Tyrväinen & Silvennoinen, 2008, *Health & Place*, 14(4)），6 題、1–7 分，內容涵蓋放鬆與平靜、注意力恢復、思緒清晰。依原量表的用法，**只在活動結束後施測**（原量表問的是造訪之後的感受）。開始前只問一題「此刻你有多放鬆」作為基準，避免一進來就要填一堆問卷。
2. **環境的恢復性知覺**（這個虛擬園子像不像一個具恢復性的環境）：知覺恢復量表短版 PRS-11（Pasini, Berto, Brondino, Hall & Ortner, 2014, *Procedia – Social and Behavioral Sciences*, 159, 293–297；題目依原文 Appendix A）。由 Hartig 等人（1997a）26 題的 PRS 經認知訪談與驗證性因素分析精簡而來，11 題、四個分量表：吸引（3 題）、遠離（3 題）、一致（3 題）、範圍（2 題），全為正向題。量尺依原文為 0～10（0＝完全不符合、6＝相當符合、10＝完全符合），指導語為「這句話有多符合我在那裡的經驗？」。原作者因「相容性」題目在過往研究中無法形成穩定因素而刪除，本研究改由行為資料（自己決定停留多久、何時結束）觀察相容性。只在後測問。
3. **過程**：每一段之後的單題放鬆自評（0–10），加上走動軌跡、停留時間、看月亮花多久等行為紀錄。

> **注意**：目前的中文題目是研究者暫譯，尚未經過「翻譯—回譯—專家審查—預試」與信效度檢驗。正式研究應採用已發表、經驗證的中文版（或完成上述程序），並在報告中說明。若需要完整的四成分（含相容性），可改用 Hartig 等人（1997）的 PRS 原版。虛擬環境研究另常加測臨場感（如 IPQ）與動暈不適（SSQ）作為控制變項。

## 下載的紀錄格式

| 欄位 | 說明 |
| --- | --- |
| `t_ms` | 從開始算起的毫秒數 |
| `type` | 事件類型（見下表） |
| `id` | 題目、段落或物件代號 |
| `value` | 評分、位置等 |

| 事件 | 意義 |
| --- | --- |
| `session_start` | 開始；`id` 是畫質等級，`value` 是開始時間 |
| `rating` | 評分 |
| `action_start`、`action_complete` | 每一段的開始與完成 |
| `interact` | 互動（推門、拔草、播種、舀水、澆水、扛鋤頭⋯⋯） |
| `pos` | 每 0.5 秒一次的位置與朝向：`x;z;朝向（弧度）` |
| `walk_home` | 黃昏走回家的開始與抵達 |
| `moon_up`、`moon_gaze` | 月亮升起時人在哪裡（`x;z`）；從月亮升起到抬頭看到它花了幾毫秒 |
| `linger` | 黃昏從豆田走回家門花了幾毫秒 |
| `seedling_touch`、`seedling_touch_total` | 除草時點到豆苗（誤觸）的次數，作為專注程度的行為指標 |
| `arrive` | 抵達豆田 |
| `auto_walk` | 使用「帶我過去」 |
| `hold_done`、`hold_release` | 按住動作完成（`value`＝按了幾毫秒），或太早放手（`value`＝毫秒;完成比例） |
| `weed_drop` | 拔起的草放進竹簍；放法（`drag` 拖放、`tap` 點竹簍、`button` 按鈕） |
| `coach` | 顯示了哪一張教學卡 |
| `verse` | 出現了哪一句詩（`id`），`value` 是觸發方式（例如 `moon_gaze` 看月亮、`narrow` 走進小徑、`arrival` 保底） |
| `scroll_open` | 打開詩卷 |
| `wet` | 回家路上衣襬濕透時，距離出發幾毫秒 |
| `sit_duration` | 窗邊坐下到選擇「結束今天」的毫秒數；`stay_longer` 表示選了再坐一會兒 |
| `tap_walk` | 點地面或點遠處物件而自動走過去，`value` 是目的地 |
| `soundscape` | 聲景切換（city、garden、night） |
| `poem_shown`、`help_open`、`sound`、`miss`、`too_far` | 其他介面事件 |
| `perf` | 前 5 秒的每秒畫格數，太低時會自動降解析度 |
| `session_end` | 結束 |

時間戳可以和心率帶等穿戴裝置的資料對齊。

## 畫質

會依裝置自動選擇（電腦 high、平板 mid、手機 low），也可以在網址後加 `?q=low`、`?q=mid`、`?q=high` 指定。

## 在自己的電腦上開啟

瀏覽器不允許直接雙擊 `index.html` 讀取檔案，需要透過網址開啟：

- 線上版本：GitHub Pages 的網址。
- 本機測試：在這個資料夾執行 `python3 -m http.server`，再打開 `http://localhost:8000`。

## 技術與限制

- 3D 使用 [three.js](https://threejs.org/) r160。場景、材質與聲音都是程式產生的數位模擬，沒有使用第三方美術素材。正式研究可換成實地拍攝的材質與音量校正過的實地錄音。
- 詩句皆為公版古典作品。
