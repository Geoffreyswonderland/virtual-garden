# 歸園田居：虛擬園藝活動雛形

中興大學園藝學系造園組專題討論的展示雛形。以陶淵明〈歸園田居〉為故事線，使用者以第一人稱在一座田園裡**自由走動**：從城市的聲音中推開柴門，清晨在菜圃除草、正午到豆田播種澆水，黃昏扛起鋤頭沿著小路走回草屋（天色隨著走回家的距離漸漸變暗），最後在月下停留看露水。每一段結束後浮現對應的詩句，並請使用者評一次此刻的放鬆程度。結束時顯示放鬆程度的時間軸與走動軌跡俯視圖，並可下載完整的事件紀錄。

本雛形用來展示**過程測量**的可能性：傳統研究只在活動前後各測一次，這裡記錄的是活動進行中的變化，以及走動軌跡、停留時間這類行為資料。

> 這是展示與可行性測試用的雛形，不收集受試者資料。紀錄只存在使用者自己的裝置上，除非他按下「下載紀錄」。

## 操作

- **點地面**：點一下地面就會走過去（最直覺，平板和電腦都適用）。
- **搖桿**：往上推前進、往下退後、往左右推是轉身（不是側移）。平板上，左手拇指放在畫面左下任何地方，搖桿就會出現在那裡。
- **鍵盤**：W／S 或 ↑／↓ 前進後退，A／D 或 ←／→ 轉向，Q／E 側移，按住 Shift 走快一點。
- **環顧**：在畫面上拖曳（滑鼠：畫面跟著手的方向轉；觸控：景物跟著手指移動，和街景地圖一樣）。
- **互動**：點東西本身（太遠會自動走到旁邊），或走近後點右下角的圓形按鈕。
- **拔草**：按住草本身（或右下角按鈕、空白鍵），草會抖動、慢慢鬆動，按夠久才連根帶土拔起；太早放手會縮回去。拔起的草只能放進菜圃旁的竹簍（上方有「竹簍」標示）：手指不放、拖到竹簍上再放開；或拿在手上走到竹簍旁，點竹簍或按「放進竹簍」。
- **澆水**：按住才會倒水，放開就停，豆苗隨水量長出來。
- **帶我過去**：右上角任務框裡的連結，會沿著小路自動走到目標（紀錄裡會記下使用次數）。

為了降低頭暈，沒有走路晃動，起步和停下都有緩衝。

## 檔案結構

```
index.html             頁面骨架與介面文字
css/style.css          介面樣式
js/main.js             故事流程、互動、介面、紀錄與結果頁
js/controls.js         搖桿、鍵盤、視角、碰撞、自動帶路
js/audio.js            聲景（城市、田園、夜晚）與音效，瀏覽器即時合成
js/csv.js              讀取 CSV
js/world/layout.js     所有物件的位置（改配置從這裡改）
js/world/env.js        天空、光線、晨昏預設、後製（光束、泛光、調色）、畫質分級
js/world/terrain.js    地面（草地、泥土路、田土混合）
js/world/grass.js      草葉與野花
js/world/plants.js     柳、榆、桃李、灌木、蘆葦
js/world/build.js      草屋、柴籬與柴門、東籬、菜圃、豆田、工具、水池
js/world/atmos.js      遠山與山嵐、遠村炊煙、歸鳥、露水、螢火蟲、蝴蝶
lib/three/             three.js r160（MIT），放在本地，離線也能開
textures/              材質圖，全部由 tools/make_textures.py 程式產生
data/actions.csv       每一段的旁白、任務、詩句、理論依據
data/questions.csv     前測與後測題目
```

## 用 Excel 修改內容

旁白、任務文字、詩句和題目都放在 `data/` 的兩個 CSV 檔裡，改內容不需要動程式。

1. 用 Excel 打開 CSV，修改文字。
2. 另存新檔時選 **「CSV UTF-8（逗號分隔）」**，否則中文會變成亂碼。
3. 把檔案上傳回 GitHub 的 `data/` 資料夾，覆蓋原檔。也可以直接在 GitHub 網頁上點檔案、按鉛筆圖示編輯。

### actions.csv 欄位

| 欄位 | 說明 |
| --- | --- |
| `id` | 段落代號，英文，不可重複 |
| `order` | 出現順序 |
| `name` | 段落名稱，例如「理荒穢」，顯示在左上角 |
| `target` | 對應的互動程式：`gate`（推柴門）、`weeds`（除草）、`sow`（種子袋→播種→舀水澆水）、`hoe`（扛鋤頭走回家）、`linger`（月下停留） |
| `time_of_day` | 這一段的時段：`morning`、`noon`、`dusk`、`night` |
| `time_label` | 左上角顯示的時辰，例如「卯時・清晨」 |
| `narration` | 每段開始時，對話框裡的旁白 |
| `task`、`task_2`、`task_3` | 右上角任務框的文字；`sow` 用到三個，`hoe` 用到兩個 |
| `poem`、`poem_source`、`poem_note` | 完成後浮現的詩句、出處與白話 |
| `rating_prompt` | 段落結束後的評分題目 |
| `theory` | 這一段的理論依據（只作紀錄，不會顯示） |

### questions.csv 欄位

| 欄位 | 說明 |
| --- | --- |
| `phase` | `pre`＝開始前，`post`＝結束後 |
| `text` | 題目 |
| `subscale` | 所屬分量表，會顯示在結果頁 |
| `min`、`max`、`min_label`、`max_label` | 滑桿範圍與兩端文字 |

目前的知覺恢復題目是依概念改寫的**示意題目**，正式研究需使用經驗證的中文版量表。

## 下載的紀錄格式

| 欄位 | 說明 |
| --- | --- |
| `t_ms` | 從開始算起的毫秒數 |
| `type` | 事件類型（見下表） |
| `id` | 題目、段落或物件代號 |
| `value` | 評分、位置等 |

| 事件 | 意義 |
| --- | --- |
| `session_start` | 開始；`id` 是畫質等級，`value` 是開始時間 |
| `rating` | 評分 |
| `action_start`、`action_complete` | 每一段的開始與完成 |
| `interact` | 互動（推門、拔草、播種、舀水、澆水、扛鋤頭⋯⋯） |
| `pos` | 每 0.5 秒一次的位置與朝向：`x;z;朝向（弧度）` |
| `walk_home` | 黃昏走回家的開始與抵達 |
| `linger`、`linger_distance` | 月下停留的毫秒數與這段時間走了幾公尺 |
| `auto_walk` | 使用「帶我過去」 |
| `hold_done`、`hold_release` | 按住動作完成（`value`＝按了幾毫秒），或太早放手（`value`＝毫秒;完成比例） |
| `weed_drop` | 拔起的草放進竹簍；放法（`drag` 拖放、`tap` 點竹簍、`button` 按鈕） |
| `tap_walk` | 點地面或點遠處物件而自動走過去，`value` 是目的地 |
| `soundscape` | 聲景切換（city、garden、night） |
| `poem_shown`、`help_open`、`sound`、`miss`、`too_far` | 其他介面事件 |
| `perf` | 前 5 秒的每秒畫格數，太低時會自動降解析度 |
| `session_end` | 結束 |

時間戳可以和心率帶等穿戴裝置的資料對齊。

## 畫質

會依裝置自動選擇（電腦 high、平板 mid、手機 low），也可以在網址後加 `?q=low`、`?q=mid`、`?q=high` 指定。

## 在自己的電腦上開啟

瀏覽器不允許直接雙擊 `index.html` 讀取檔案，需要透過網址開啟：

- 線上版本：GitHub Pages 的網址。
- 本機測試：在這個資料夾執行 `python3 -m http.server`，再打開 `http://localhost:8000`。

## 技術與限制

- 3D 使用 [three.js](https://threejs.org/) r160。場景、材質與聲音都是程式產生的數位模擬，沒有使用第三方美術素材。正式研究可換成實地拍攝的材質與音量校正過的實地錄音。
- 詩句皆為公版古典作品。
