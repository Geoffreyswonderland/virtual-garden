# 歸園田居：虛擬園藝活動雛形

中興大學園藝學系造園組專題討論的展示雛形。以陶淵明〈歸園田居〉為故事線，使用者以第一人稱在一座田園裡**自由走動**，過完一天：

| 段落 | 時辰 | 做什麼 | 出現的詩句 |
| --- | --- | --- | --- |
| 返自然 | 清晨 | 在柴門外聽著車馬聲，推開柴門 | 久在樊籠裡，復得返自然（其一） |
| 理荒穢 | 早晨 | 在菜圃按住拔草，丟進竹簍 | 晨興理荒穢 |
| 種豆 | 正午 | 拿鋤頭挖洞、放豆、蓋土、插好鋤頭、舀水澆水 | 種豆南山下，草盛豆苗稀 |
| 荷鋤歸 | 黃昏 | 扛起插在豆田裡的鋤頭，沿來時的路走回草屋；通往家門的最後一段沒人除草，兩旁的草比人高，把路擠成窄窄一條；天色隨著走近家門變暗，月亮從草屋上方升起，畫面邊緣的箭頭會指出月亮在哪，抬頭看它一會兒 | 帶月荷鋤歸，道狹草木長 |
| 夕露 | 夜 | 走進草地，衣襬被露水沾濕；選擇再走走或回屋 | 夕露沾我衣，衣沾不足惜 |
| 歸 | 夜深 | 推門進屋（屋裡有木榻、灶、水缸、茶具、無弦琴與酒罈），把鋤頭掛到進門左手邊牆上的木釘（發亮的輪廓標出位置，點牆上的木架即可），坐到窗邊；自己決定何時結束 | 但使願無違 |

〈歸園田居〉其三的每一句，都在對應的動作或地點出現（有保底，不會漏掉）；另有 5 張「詩箋」（其一的景物詩句與〈飲酒〉其五）散落在園子裡，找不找得到都沒關係。找到的詩句收在選單的「詩卷」裡。

每一段結束時，只問一題「此刻有多放鬆」（同一張卡片上會列出這段遇到的詩句）；最後的幾題在故事結束後，集中在同一頁作答。結果頁顯示放鬆程度的時間軸與走動軌跡俯視圖，並可下載完整的事件紀錄。

本雛形用來展示**過程測量**的可能性：傳統研究只在活動前後各測一次，這裡記錄的是活動進行中的變化，以及走動軌跡、停留時間、看月亮、走進草地這類行為資料。

> 這是展示與可行性測試用的雛形，不收集受試者資料。紀錄只存在使用者自己的裝置上，除非他按下「下載紀錄」。

## 操作

- **點地面**：點一下地面就會走過去（最直覺，平板和電腦都適用）。
- **搖桿**：往上推前進、往下退後、往左右推是轉身（不是側移）。平板上，左手拇指放在畫面左下任何地方，搖桿就會出現在那裡。
- **鍵盤**：W／S 或 ↑／↓ 前進後退，A／D 或 ←／→ 轉向，Q／E 側移，R／F（或 PageUp／PageDown）抬頭、低頭，按住 Shift 走快一點。
- **環顧**：在畫面上拖曳，景物會跟著手移動（滑鼠和觸控都一樣，和街景地圖相同）。
- **互動**：點東西本身（太遠會自動走到旁邊），或走近後點右下角的圓形按鈕。
- **拔草**：按住草本身、右下角按鈕或空白鍵，草會抖動、慢慢鬆動，按夠久才連根帶土拔起；太早放手會縮回去。拔起的草只能放進菜圃前的竹簍（上方有「竹簍」標示）。按住草本身拔的，可以手指不放、直接拖到竹簍上放開；用按鈕或空白鍵拔的，草會拿在手上跟著你轉身，轉向竹簍後點竹簍、按「丟進竹簍」或空白鍵就丟進去（4.5 公尺內都可以）。
- **種豆**（點播）：拿起木樁旁的鋤頭 → 在插著小枝的三個地方按住挖洞（鋤頭會一下一下挖下去）→ 拿種子袋，走到每個洞旁邊蹲下，放進三顆豆子 → 按住用鋤頭把挖出來的土蓋回去 → 把鋤頭插在田邊（黃昏再回來扛回家）→ 到水桶點一下，用水瓢舀起一瓢水（看得到瓢裡的水）→ 拿著水瓢走到每個土堆旁，按住澆水，水瓢會傾斜倒水，土堆變深色、瓢裡的水變少。豆子不會當場發芽。要播種的那一壟清晨已除過草，其他壟仍是「草盛豆苗稀」。
- **帶我過去**：右上角任務框裡的連結，會沿著小路自動走到目標（紀錄裡會記下使用次數）。

為了降低頭暈，沒有走路晃動，起步和停下都有緩衝。

每一段有多個步驟時，任務框下方會列出步驟，目前這一步會亮起；第一次遇到新動作（拔草、挖洞、放豆、蓋土、澆水）時，畫面下方會出現一張簡短的教學卡。可以互動的地方地上會有發亮的圈圈，走到夠近時圈圈變綠，上方會出現動作名稱。

## 用 Excel 修改內容

旁白、任務文字、詩句和題目都放在 `data/` 的兩個 CSV 檔裡，改內容不需要動程式。

1. 用 Excel 打開 CSV，修改文字。
2. 另存新檔時選 **「CSV UTF-8（逗號分隔）」**，否則中文會變成亂碼。
3. 把檔案上傳回 GitHub 的 `data/` 資料夾，覆蓋原檔。也可以直接在 GitHub 網頁上點檔案、按鉛筆圖示編輯。

### 問卷的學理依據

測量分三層，各對應一組題目：

1. **恢復結果**（使用者有沒有恢復）：恢復結果量表 Restoration Outcome Scale（ROS；Korpela, Ylén, Tyrväinen & Silvennoinen, 2008, *Health & Place*, 14(4)），6 題、1–7 分，內容涵蓋放鬆與平靜、注意力恢復、思緒清晰。**前後測各一次**，看變化量。
2. **環境的恢復性知覺**（這個虛擬園子像不像一個具恢復性的環境）：知覺恢復量表 Perceived Restorativeness Scale（PRS；Hartig, Korpela, Evans & Gärling, 1997），依注意力恢復理論的四個成分：遠離（5 題）、吸引（8 題）、一致（4 題，皆反向題）、相容（5 題），0–6 分；原量表另有 4 題「易讀性」題目，非四個成分，未納入。只在後測問。
3. **過程**：每一段之後的單題放鬆自評（0–10），加上走動軌跡、停留時間、看月亮花多久等行為紀錄。

> **注意**：目前的中文題目是研究者暫譯，尚未經過「翻譯—回譯—專家審查—預試」與信效度檢驗。正式研究應採用已發表、經驗證的中文版（或完成上述程序），並在報告中說明。PRS 也有 11 題短版（PRS-11；Pasini, Berto, Brondino, Hall & Ortner, 2014）可減輕作答負擔。虛擬環境研究另常加測臨場感（如 IPQ）與動暈不適（SSQ）作為控制變項。

## 下載的紀錄格式

| 欄位 | 說明 |
| --- | --- |
| `t_ms` | 從開始算起的毫秒數 |
| `type` | 事件類型（見下表） |
| `id` | 題目、段落或物件代號 |
| `value` | 評分、位置等 |

| 事件 | 意義 |
| --- | --- |
| `session_start` | 開始；`id` 是畫質等級，`value` 是開始時間 |
| `rating` | 評分 |
| `action_start`、`action_complete` | 每一段的開始與完成 |
| `interact` | 互動（推門、拔草、播種、舀水、澆水、扛鋤頭⋯⋯） |
| `pos` | 每 0.5 秒一次的位置與朝向：`x;z;朝向（弧度）` |
| `walk_home` | 黃昏走回家的開始與抵達 |
| `moon_up`、`moon_gaze` | 月亮升起時人在哪裡（`x;z`）；從月亮升起到抬頭看到它花了幾毫秒 |
| `linger`、`linger_distance` | 月下停留的毫秒數與這段時間走了幾公尺 |
| `auto_walk` | 使用「帶我過去」 |
| `hold_done`、`hold_release` | 按住動作完成（`value`＝按了幾毫秒），或太早放手（`value`＝毫秒;完成比例） |
| `weed_drop` | 拔起的草放進竹簍；放法（`drag` 拖放、`tap` 點竹簍、`button` 按鈕） |
| `coach` | 顯示了哪一張教學卡 |
| `verse` | 出現了哪一句詩（`id`），`value` 是觸發方式（例如 `moon_gaze` 看月亮、`narrow` 走進小徑、`arrival` 保底） |
| `scroll_open` | 打開詩卷 |
| `wet` | 衣襬濕透花了幾毫秒 |
| `dew_choice` | 衣裳濕了之後的選擇：`keep_walking` 或 `go_in` |
| `sit_duration` | 窗邊坐下到選擇「結束今天」的毫秒數；`stay_longer` 表示選了再坐一會兒 |
| `tap_walk` | 點地面或點遠處物件而自動走過去，`value` 是目的地 |
| `soundscape` | 聲景切換（city、garden、night） |
| `poem_shown`、`help_open`、`sound`、`miss`、`too_far` | 其他介面事件 |
| `perf` | 前 5 秒的每秒畫格數，太低時會自動降解析度 |
| `session_end` | 結束 |

時間戳可以和心率帶等穿戴裝置的資料對齊。

## 畫質

會依裝置自動選擇（電腦 high、平板 mid、手機 low），也可以在網址後加 `?q=low`、`?q=mid`、`?q=high` 指定。

## 在自己的電腦上開啟

瀏覽器不允許直接雙擊 `index.html` 讀取檔案，需要透過網址開啟：

- 線上版本：GitHub Pages 的網址。
- 本機測試：在這個資料夾執行 `python3 -m http.server`，再打開 `http://localhost:8000`。

## 技術與限制

- 3D 使用 [three.js](https://threejs.org/) r160。場景、材質與聲音都是程式產生的數位模擬，沒有使用第三方美術素材。正式研究可換成實地拍攝的材質與音量校正過的實地錄音。
- 詩句皆為公版古典作品。
